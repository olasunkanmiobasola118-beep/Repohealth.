About RepoHealth

A clearer first look at open source.

RepoHealth is an open-source tool for reviewing the visible foundations of public GitHub repositories. It uses GitHub’s public API, does not run code from the projects it scans, and explains when a check could not be assessed. Treat every report as a starting point for human review.
