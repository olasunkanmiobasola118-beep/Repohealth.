What RepoHealth checks

Six categories, each scored separately and combined into one overall score.

Documentation

README, license, and whether the docs explain how to install and use the project.

Security hygiene

Security policy, risky configuration, and signs of exposed secrets.

Testing

Test folders, test configuration, and automated workflows that run tests.

Maintainability

How recently the project was updated and how its issues are managed.

Dependencies

Dependency manifests and lockfiles for common languages.

Contribution readiness

Contributing guide, code of conduct, and issue and pull request templates.

About RepoHealth

RepoHealth is an open-source tool for checking the health of public GitHub repositories. It reads repository data through GitHub's public API and never runs code from the repositories it scans.

Every report separates three kinds of output: objective checks, heuristic warnings, and AI-generated suggestions. A clean report does not prove a project is secure.

Ways to contribute

  • Frontend: improve layout, accessibility, and design
  • Documentation: tutorials, examples, and translations
  • Testing: add tests for scanner and scoring rules
  • Scanner rules: propose and implement new checks
  • AI providers: add support for other open-weight model runtimes

Contribution guidelines will be added to the project repository before it is opened to the community.
